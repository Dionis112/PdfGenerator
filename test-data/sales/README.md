# Корпус отчётов по продажам

`input.xml` и `sales-report-1.xsl` адаптированы из
[AltovaGen, коммит 91aa24d](https://github.com/BolotnikovPS/AltovaGen/tree/91aa24ddb9337114ae3ddc926a489d45d3dcb0c5/tests/AltovaGen.UnitTests).
Оригинальная лицензия MIT сохранена в `LICENSE.AltovaGen.txt` (Copyright © 2026 BolotnikovPS).
Файлы содержат синтетические данные.

В `sales-report-1.xsl` общий итог вычисляется рекурсивным шаблоном XSLT 1.0.
`sales-report-2.xsl` использует сумму отдельных произведений XPath 2.0.
Шрифт наследуется от `sans-serif`, используется обычное начертание встроенного шрифта PdfGenerator.
Итоги форматируются без экспоненциальной записи. Нижний итог таблицы помещён перед `table-body`
согласно модели XSL-FO; пустой отчёт выводит строку «Нет позиций» и нулевой итог.
Динамический XPath исходного примера заменён обычным XPath; `altova:evaluate` для этого корпуса не требуется.

Интеграционные тесты проверяют четыре строки, суммы 12 000 000 / 8 750 000 / 2 400 000 / 3 500 000,
общий итог 26 650 000, кириллицу, заголовки и нижний колонтитул.
Оба шаблона проходят полный рендеринг PDF внутри процесса и через worker.
Корпус не подтверждает совместимость произвольных производственных шаблонов Altova.
