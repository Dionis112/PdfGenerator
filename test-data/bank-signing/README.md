# Банковский комплект для подписания

Добавлен `bank-altova-2012.xsl`: четыре настоящих расширения старого профиля (`evaluate`, `distinct-nodes`, автонумерация и сброс), даты — стандартный XSLT 2.0. Работает при `XmlFoOptions.Altova2012 = new()` в обоих режимах. Общий профиль проверен по документации; оригинальные эталоны Altova ещё не сняты. Старый `bank-altova.xsl` отмечается как смешанный современный профиль и сохраняет неподдержанное расширение дат.

Составной синтетический сценарий для проверки приложения: заявление и условия, график из 12 платежей, выбранные услуги, подтверждения и пустые поля подписей. Три страницы A4, кириллица, колонтитулы и номера страниц. Реальных персональных данных и подписей нет.

`input.xml` задаёт 1 200 000 руб., 12 месяцев и условные 12% годовых. Основной долг погашается равными долями; проценты рассчитываются на остаток по формуле ставка / 12. Ожидаются 78 000 руб. процентов, 1 278 000 руб. платежей и 1 500 руб. отдельно выбранных услуг. Это фиксированный тестовый расчёт, без производственных банковских правил.

## Профили одного документа

| Часть сценария | `bank-standard.xsl` | `bank-altova-2012.xsl` | `bank-altova.xsl` |
|---|---|---|---|
| Запуск | Обычный профиль | Включённый AltovaXML 2012 | Compile / XPST0017 |
| Даты платежей | `xs:date + xs:yearMonthDuration` | Стандартные даты, как слева | Неподдержанный `altova:add-months-to-date` |
| Сумма выбранных услуг | Статическое XPath-выражение `sum` | `altova:evaluate` с параметром | То же расширение |
| Номера платежей | Индекс строки | `altova:generate-auto-number` | То же расширение |
| Начало нумерации | Локальный диапазон `1 to months` | `altova:reset-auto-number` | То же расширение |
| Повторы примечаний | Группировка по нормализованному тексту | `altova:distinct-nodes` | То же расширение |

Altova-вариант импортирует стандартную вёрстку и переопределяет пять точек расширения. Это составной диагностический пример, а не подтверждённый эталон Altova: его современное расширение дат в текущем приложении не зарегистрировано, запуск завершается на Compile с XPST0017. Группировка по тексту в стандартном варианте реализует требование этого документа; тождественность общей семантике `distinct-nodes` не заявляется. Профили старых функций и современной арифметики дат смешаны намеренно для проверки приложения, совместимость такого сочетания с конкретной версией Altova не проверялась.

## Проверка

Для рабочего профиля 2012 используйте [пример публичного API](../../README.md#10-шаблоны-altovaxml-2012) или строгую приёмку из корня репозитория:

```powershell
$run = Join-Path 'artifacts/altova2012-acceptance' ([Guid]::NewGuid().ToString('N'))
dotnet run --project eng/PdfGenerator.TemplateValidation -c Release -- . $run --strict-altova2012
```

Строгая приёмка включает четыре банковских входа в InProcess/Worker с кэшем и без него: 16 банковских проверок из 70 общих. [Итоговый отчёт](../../docs/altova-2012-validation-2026-10-06.md).

Исследовательский запуск всего корпуса с отключённым профилем:

```powershell
dotnet run --project eng/PdfGenerator.TemplateValidation -c Release -- . artifacts/template-validation/my-run
python eng/verify-template-pdfs.py artifacts/template-validation/my-run
```

Выберите новый пустой каталог результата. Для второй команды нужен `pypdf`. Первая запускает весь корпус внутри процесса и через общий worker с отключённым кэшем. Проверяет все 12 строк FO, итоги, услуги, удаление повторов и число страниц. Во второй проверяются уже извлечённый текст PDF, первые/последние платежи, итоги, подписи, кириллица и совпадение страниц двух режимов.

Дополнительные XML создаются автоматически: дата 31.01.2026 (первый платёж 28.02.2026, второй 31.03.2026), отсутствие услуг, другой клиент и номер документа при переиспользовании worker. Контрольные суммы намеренно фиксированы под этот вход; при изменении сценария нужно обновить независимые ожидания.

Полный прогон и ограничения описаны в [отчёте](../../docs/template-validation-2026-10-06.md). Этот пример проверяет генерацию содержимого и полей подписи; криптографическое подписание PDF в сценарий не входит.
